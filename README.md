# Disaster Management Application

This project is a **disaster management system** that allows for the collection of calls for help in disaster situations, their notification to authorities and their management via a map. The application was developed with React and is hosted in a **cloud environment** using Firebase Realtime Database and Firebase Hosting.

## 🛠 Technologies Used

| Technology | Description |
|------|-------------------------|
| **React.js** | Frontend user interface |
| **Firebase** | Realtime Database, Authentication, Hosting |
| **Leaflet.js** | Map display and marker usage |
| **Google Cloud** | Hosting infrastructure via Firebase |

---

## Features

- Creating a help ticket via the user panel
- Live data streaming with Realtime Database
- Seeing help tickets on a map from the authorized panel
- Changing the status of help tickets (Pending, Processing, Completed)
- Simple and responsive user interface
- Publishing on the cloud (Firebase Hosting)
